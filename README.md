## ✦ Overview

**ZAYATHON 2026** is a modern hackathon platform designed to turn an event website into a complete digital experience.

The project combines:

- A cinematic editorial-style public website
- Real-time event countdown
- Multi-member team registration
- Supabase-backed registration management
- Secure admin authentication
- Private registration dashboard
- Event management controls
- CSV export for administrators
- Responsive mobile-first interactions
- Accessibility-focused UX
- SEO and social sharing metadata
- Production deployment

Rather than treating the website as a static event brochure, this project was designed as a **small production web application** with a public experience and a private operational layer.

---

# 🎯 Project Goals

The platform was designed around five primary goals:

### 01 — EXPERIENCE

Create a hackathon website that feels like a technology product rather than a traditional event template.

### 02 — CONVERSION

Make the path from discovering ZAYATHON → understanding the event → registering a team simple and focused.

### 03 — OPERATIONS

Give organizers a private interface to manage registrations and event information.

### 04 — SECURITY

Keep participant information private while allowing public registration.

### 05 — QUALITY

Deliver a responsive, accessible and production-ready experience across desktop and mobile devices.

# ✦ Design Direction

The visual identity intentionally moves away from the typical:

> "dark background + neon gradient + glass cards"

hackathon aesthetic.

Instead, ZAYATHON uses an **editorial / cinematic design language**.

### Visual principles

- Cinematic hero video
- Warm off-white editorial surfaces
- High-contrast typography
- Strong typographic hierarchy
- Generous whitespace
- Minimal card usage
- Subtle borders
- Blue as a restrained accent
- Full-screen visual moments
- Editorial section numbering
- Controlled motion
- Responsive interaction design
